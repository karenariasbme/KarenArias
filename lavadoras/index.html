¿Por qué es seguro?

  • Contraseñas cifradas y conexión segura HTTPS
  • Cada registro está protegido con reglas de acceso: sin usuario de la lavadora no se ve nada
  • La información vive en la nube, no en una sola computadora
  • El código se guarda en un repositorio profesional con control de versiones

¿Por qué no hay mensualidad?

El sistema se aloja en GitHub y usa Supabase como base de datos, ambos en su plan gratuito. Ese plan alcanza para miles de cambios de aceite, más que suficiente para una lavadora.

Opcional, no incluido: dominio propio (ej. milavadora.com), aprox. $15 al año.
