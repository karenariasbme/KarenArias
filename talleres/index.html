¿Por qué es seguro?

  • Contraseñas cifradas y conexión segura HTTPS
  • Cada registro está protegido con reglas de acceso: sin usuario del taller no se ve nada
  • La información vive en la nube, no en una sola computadora
  • El código se guarda en un repositorio profesional con control de versiones

¿Por qué no hay mensualidad?

El sistema se aloja en GitHub y usa Supabase como base de datos, ambos en su plan gratuito. Ese plan alcanza para miles de órdenes de trabajo, más que suficiente para un taller.

Opcional, no incluido: dominio propio (ej. mitaller.com), aprox. $15 al año.
